# خريطة CooffeUp

## منجز

- كتالوج المنتجات والبحث والباركود والسلة، وتسعير صحيح بالهللات، وضريبة القيمة المضافة، وخصومات على البند والطلب.
- دفع نقدي وبطاقات ومدى وApple Pay وSTC Pay، ودفع مجزأ، وحساب الباقي.
- منع تكرار الطلبات بمفتاح idempotency، وخصم المخزون، والتحقق من التوفر.
- البيع دون إنترنت: صندوق صادر على الجهاز، ومزامنة تلقائية، وتعليم تعارضات المخزون، وتعليق السلات، وService Worker.
- محاسبة بالقيد المزدوج مؤتمتة، ودليل حسابات، وميزان مراجعة، وقائمة دخل، وإقرار ضريبة، وقيود يدوية، وتصدير.
- المشتريات مع قارئ الفواتير الذكي (OCR)، ومتوسط التكلفة المرجح، والمصروفات.
- الورديات وإغلاق الصندوق وترحيل الفروقات.
- إدارة العملاء: تشفير البيانات الحساسة، والسلوك الشرائي، والشرائح، والعروض المقترحة.
- دخول بالرمز السري مع قفل بعد المحاولات الخاطئة، و22 صلاحية و5 أدوار، ومنح وسحب لكل موظف، وسجل تدقيق.
- ربط زد وسلة: طلبات واردة، ومزامنة المخزون والأسعار صادرة.
- تطبيقات التوصيل في شاشة موحدة مع محلي وسفري.
- القطاعات: طاولات وشاشة مطبخ، ومواعيد مع منع التعارض، وتجزئة.
- 29 تقريرًا دوريًا.
- إرسال الفاتورة برسالة SMS مع صفحة فاتورة عامة ورمز QR بصيغة هيئة الزكاة.
- Webhooks موقّعة للأنظمة المحاسبية وتطبيقات سوق زد.
- برنامج ولاء بالنقاط والمستويات والمشروب المجاني، مع عكس النقاط عند الاسترجاع.
- إلزام الوردية المفتوحة للبيع، وحركات النقد، وتقرير الوردية، واسترجاع بطريقة الدفع الأصلية دون انحراف في تقريب الضريبة.
- واجهة عربية وإنجليزية كاملة مع RTL وLTR لكل الشاشات، بما فيها الإدارة والتقارير والمحاسبة والمشتريات.
- حفظ دائم للبيانات في ملف لقطة ذري (Snapshot) مع مفاتيح تطوير محفوظة، فلا تضيع البيانات عند إعادة التشغيل.
- تعدد الفروع والبوثات المؤقتة للمعارض بمخزون مستقل لكل فرع، وتحويلات مخزون، وإغلاق البوث وإرجاع مخزونه، ومزامنة المتجر بإجمالي المخزون.
- شاشة الطلبات والمرتجعات: بحث، واسترجاع جزئي أو كامل، وإعادة إرسال الفاتورة.
- لوحة تحكم موحدة للمالك: مبيعات اليوم لكل قناة وفرع، والطلبات المنتظرة، وتنبيهات المخزون والتكاملات.
- شاشة الاستلام للمغاسل والخياطة مع إشعار SMS عند الجاهزية.
- تطبيق الجوال (iOS وAndroid) بـ Expo مرتبط بالـ API مع البيع دون إنترنت والوردية.

## قبل الإطلاق التجاري

1. PostgreSQL ومعاملات قاعدة بيانات وmigrations ونسخ احتياطي. الحفظ الحالي بملف لقطة مناسب لفرع أو عدة فروع صغيرة، ومصمم ليُستبدل بجداول.
2. اعتماد شريك رسمي مع زد وسلة وكل تطبيق توصيل، والتحقق من صيغ الـ Webhook ونقاط تحديث المخزون في بيئة الاختبار لكل منصة.
3. تكامل جهاز الدفع عبر مزود سعودي معتمد، وطابعة حرارية ودرج نقدي.
4. الفوترة الإلكترونية، المرحلة الثانية: توليد UBL XML والتوقيع والإرسال لمنصة "فاتورة" حسب الموجة المطلوبة.
5. مزود SMS فعلي باسم مرسل مسجل لدى هيئة الاتصالات، وإدارة موافقات التسويق.
6. تطبيق الجوال: بقية شاشات الإدارة (حاليًا نقطة البيع والوردية)، والنشر على المتاجر عبر EAS.
7. الوصفات والهدر والجرد الدوري والموردون والمدفوعات الآجلة.
8. اختبارات تكامل وواجهة وأحمال وأمان، ومراقبة وتنبيهات، وخطة تعافٍ من الكوارث، وتدوير المفاتيح.
9. الولاء: انتهاء صلاحية النقاط، وهدية الميلاد، والإحالات، والحملات، وموافقة العميل على الرسائل.
10. أسماء المنتجات والتصنيفات والطاولات التي يدخلها المستخدم بلغتين (الأسماء الافتراضية مترجمة).

> لا ينبغي استخدام النظام لمعالجة مدفوعات حقيقية قبل إكمال عناصر الإطلاق أعلاه ومراجعة التكاملات النظامية.
