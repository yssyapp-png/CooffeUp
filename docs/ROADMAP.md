# خريطة CooffeUp

## النسخة الحالية: نواة نقطة البيع

- كتالوج المنتجات والبحث والسلة.
- تسعير صحيح بالهللات وضريبة قيمة مضافة وخصومات.
- دفع نقدي، بطاقات، مدى، Apple Pay وSTC Pay على مستوى النطاق.
- منع تكرار الطلبات بمفتاح idempotency.
- خصم المخزون والتحقق من التوفر.
- واجهة عربية متجاوبة وتطبيق Expo للجوال واللوحي.
- حماية HTTP وتحديد معدل الطلبات والتحقق الصارم من المدخلات.

## قبل الإطلاق التجاري

1. PostgreSQL ومعاملات قاعدة بيانات، migrations ونسخ احتياطي.
2. دخول آمن، MFA، أدوار وصلاحيات دقيقة، وإدارة الورديات والصندوق.
3. تكامل جهاز الدفع عبر مزود سعودي معتمد، وطابعة حرارية ودرج نقدي وباركود.
4. إدارة الفروع والمخازن والموردين والوصفات والهدر والتحويلات والجرد.
5. الطلبات المعلقة، تقسيم الفاتورة، الاسترجاع، الإلغاء بموافقة مدير، والبقشيش.
6. وضع offline-first مع طابور مزامنة مشفر وحل تعارضات دون بيع مخزون مزدوج.
7. فواتير إلكترونية متوافقة مع متطلبات هيئة الزكاة والضريبة والجمارك ومرحلة الربط المناسبة.
8. لوحة تقارير، إقفال يومي، فروقات الصندوق، تكلفة البضاعة وهوامش الربح.
9. اختبارات تكامل وواجهة وأحمال وأمان، مراقبة وتنبيهات وخطة تعافٍ من الكوارث.

> لا ينبغي استخدام النواة الحالية لمعالجة مدفوعات حقيقية قبل إكمال عناصر الإطلاق أعلاه ومراجعة التكاملات النظامية.
