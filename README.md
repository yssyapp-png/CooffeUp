# CooffeUp

منصة نقاط بيع ومحاسبة للمقاهي والمطاعم والتجزئة والخدمات، تعمل على الويب والجوال ببنية موحدة ودعم عربي/إنجليزي.

## التشغيل

```bash
npm install
cp apps/api/.env.example apps/api/.env
npm run dev
```

- الويب: `http://localhost:5173`
- API: `http://localhost:4000`
- فحص الصحة: `http://localhost:4000/health`

حسابات التجربة (بيئة التطوير فقط): المالك `1111`، مديرة الفرع `2222`، الكاشير `3333`، المطبخ `4444`، المحاسب `5555`.

## تطبيق الجوال (iOS وأندرويد)

```bash
npm run dev:mobile
```

- **على المحاكي:** يتصل التطبيق تلقائيًا بالخادم (أندرويد عبر `10.0.2.2:4000`، وiOS عبر `localhost:4000`).
- **على جوال حقيقي** بتطبيق Expo Go وعلى نفس شبكة الـ Wi-Fi:
  1. اجعل الخادم يستقبل من الشبكة بإضافة `HOST=0.0.0.0` إلى `apps/api/.env`.
  2. اعرف عنوان جهازك بالأمر `ipconfig getifaddr en0`.
  3. في شاشة دخول التطبيق اضغط "عنوان الخادم" واكتب مثلًا `http://192.168.1.20:4000`.

يدعم التطبيق الدخول بالرمز السري، والبيع، والولاء والمشروب المجاني، والورديات، والفروع، والبيع دون إنترنت مع المزامنة التلقائية.

## قبل التشغيل الفعلي

راجع `docs/ROADMAP.md`. تنبيهات مهمة:

- **البيانات في الذاكرة:** تُفقد عند إعادة تشغيل الخادم. PostgreSQL أول بند قبل الإطلاق.
- **زد وسلة وتطبيقات التوصيل:** تتطلب حسابات شريك واعتماد رسمي من كل منصة. صيغ الـ Webhook مبنية على وثائقها العامة، ويجب التحقق من الحقول في بيئة الاختبار (Sandbox) لكل منصة قبل التشغيل. رابط تحديث المخزون يُدخل من بوابة مطوري المنصة.
- **SMS:** يحتاج مزود رسائل سعوديًا واسم مرسل مسجلًا. الوضع الافتراضي `log` لا يرسل فعليًا.
- **OCR:** يحمّل Tesseract ملفات اللغة من CDN عند أول استخدام، ويحتاج اتصالًا في تلك المرة.
- **الفوترة الإلكترونية:** رمز QR يغطي المرحلة الأولى. أما الربط والتوقيع مع منصة "فاتورة" (المرحلة الثانية) فغير منفذ بعد.
